its own plan producing working, testable software. Order is dependency order.
Spec of record: `docs/handoff/MASTER PROMPT.md` + `docs/handoff/DECISIONS.md`;
visual truth: `docs/handoff/design-reference/` (inventoried in
`docs/handoff/design-inventory.md`).

Standing constraints (all plans): money is integer cents; one total bankroll;
no skip feature; no promo strategy; UI copy verbatim from design; never render
the words "append-only", "ghost", "picker", "grader", "CLV", "gatekeeper"
(say "closing price edge", "double verification"); quiet hours 00:00–08:00
America/Vancouver; data kept forever (export, never delete); server port 4400,
Vite dev port 5174.
